# 知见 · 多平台帖子监控

Windows 本地监控台，支持微博、淘股吧、知识星球与通过微信读书书架订阅的公众号。

## 快速开始

### 使用 Windows 发布包

解压整个 `zhijian-windows.zip` 文件夹，双击 `zhijian_silent.exe`。浏览器会打开 `http://127.0.0.1:8000`。`zhijian.exe` 是显示控制台的同功能版本，二者共享数据，不要同时运行。

发布包包含专用 Chromium，首次运行不用再下载浏览器。请勿只发送 exe，必须连同 `_internal` 目录一起发送。程序仅支持本机使用。

登录窗口优先使用 Edge，并保留发布包自带的 Chromium 作为备用，不依赖电脑安装 Google Chrome，也不读取日常浏览器资料。知见主页面可以在 Edge 等浏览器打开；登录辅助窗口优先使用已安装的 Edge，启动失败自动回退到自带 Chromium；两者使用独立的专用会话目录。源码运行需先由安装脚本下载 Chromium。

### 使用源码

安装 Python 3.10+，双击 `install.bat` 安装依赖和 Chromium，再双击 `start.bat`。首次安装需要联网，安装失败会停止并显示错误。运行时会自动打开浏览器。

## 连接平台与添加监控

1. 打开设置，在「连接平台账号」点击连接。知见打开独立的官方登录窗口。
2. 在窗口中完成平台提供的扫码或其他登录方式。二维码在电脑窗口显示，用手机对应 App 扫码确认。
3. 登录经只读接口验证成功后保存凭据；取消、超时或失败会保留之前的凭据。关闭设置抽屉不会取消登录，可再次打开查看进度或点击取消。
4. 在「监控对象」搜索昵称、粘贴主页链接，或从星球列表／微信读书书架选择，再点击保存。高级入口保留手动 ID；资料解析失败可选择仍然添加，格式不正确不能保存。
5. 查看各监控对象状态，确认首轮抓取完成。登录失效后点击重新连接；网络错误或限流时不应反复重新登录。

每个平台使用独立浏览器会话，不读取日常浏览器资料。会话失效或平台要求验证时仍需手动登录，不能永久免登录。后台监控不会主动弹出登录窗口。

- 微博：数字 UID，或 `https://m.weibo.cn/u/数字`。
- 淘股吧：公开主帖免登录，添加 `https://www.tgb.cn/blog/数字` 或数字 ID。可选 Cookie 不代表已验证登录权限；暂不监控跟帖。
- 知识星球：星球 ID，或 `星球ID:用户ID`；仅访问自己账号有权访问的内容。
- 公众号：先在手机微信读书 App 订阅，再连接微信读书，点击同步书架添加。

## 设置与添加对象

设置分为「监控对象／平台账号／偏好设置」。列表和偏好共用底部固定的「保存更改」按钮，切换页签保留草稿；未保存关闭会提醒。连接、取消和断开即时生效。

- 微博：可以直接搜索昵称，从头像与候选简介确认身份后添加，也支持主页链接。
- 淘股吧：粘贴博主主页链接即可预览，无需提取数字 UID；暂不提供全站昵称搜索。
- 知识星球：读取已加入的星球列表后选择，也可粘贴星球主页链接。高级输入仍支持「星球ID:用户ID」。
- 公众号：读取微信读书书架，从已订阅的公众号选择。书架列表支持按名称筛选。

监控列表恢复头像，可按名称或平台筛选；「⋯」中可更新资料、编辑本地显示名称或移除监控。暂停、移除不删除历史帖子。个人博主的帖子优先显示当前监控资料名称，星球动态保留实际发帖人的名称。

顶部显示每个平台最近检查时间、轮次间隔和下一轮倒计时。轮次间隔是整轮结束后等待的时间，不表示所有对象每隔该秒数都能检查完毕。

## 微博全文

长微博只保留一个「展开全文」按钮，移除原摘要里的重复全文链接。新帖子和已有摘要会在后台分批补齐；浏览当前列表也会按队列提前准备全文。补齐后卡片自动更新但不会自动展开，点击即可在本地展开／收起，不需要再次请求微博。

首次未准备完、登录失效或被限流时，展开仍可能需要等待；失败保留摘要并提示重试。后台队列单线程限速，并与手动请求合并去重，避免反复请求。缓存的全文也用于本地搜索。

微博表情保留原表情图片与替代文字；平台链接／视频小图标改为轻量标签。图片失败时用文字占位替代浏览器破图图标。

## 手动凭据备用入口

官方窗口无法登录时，可以展开设置里的备用入口。输入后点击保存，再点击验证连接。未编辑的空输入保持旧值；编辑后清空会删除该凭据。

在对应官网登录后，用浏览器 F12 → 网络 → 刷新，查看请求标头：

- 微博：从 `m.weibo.cn` 请求复制 Cookie，需含 `SUB`。
- 知识星球：从 `api.zsxq.com` 请求 Cookie 获取 `zsxq_access_token` 的值，或粘贴包含该字段的整条 Cookie。不是 Authorization 标头。
- 微信读书：从 `weread.qq.com` 请求复制 Cookie，含 `wr_vid`、`wr_skey`，尽量包含 `wr_rt` 等字段；可用时程序尝试续期。
- 淘股吧：公开内容不需要；可选粘贴本站 Cookie。

不要将凭据发给别人。验证只代表当时可用，不保证将来一直有效。

## 抓取范围与限制

程序按轮询间隔检查最新内容，间隔最少 30 秒。大多数平台目前仅取最新一页，公众号仅检查最新一篇；停机、多篇连续发布或平台限制可能造成漏帖。本版不补齐历史，也不承诺零遗漏。

设置支持监控列表导入导出、启用暂停、关键词搜索、图片查看和浏览器通知。浏览器通知需在设置中主动授权，且网页保持打开。新帖刷新、删除和筛选使用本地记录 ID 去重。

## 新帖通知

1. 在日常使用的浏览器打开 `http://127.0.0.1:8000`，点击设置里的通知授权按钮并选择允许。此前拒绝过的，需要在地址栏的网站权限中改为允许；`localhost` 与 `127.0.0.1` 的权限独立。
2. 在 Windows「设置 → 系统 → 通知」允许该浏览器显示通知横幅，并检查勿扰模式。
3. 保持知见网页打开、后端运行，等待实际新帖。刷新历史列表或补齐全文不会产生新帖通知。

新帖通知覆盖所有监控对象，不受当前页面的平台、作者和关键词筛选影响，同一条实时事件会去重。关闭网页后，仅保留后台 exe 无法发送此类浏览器通知。设置提供权限状态和「发送测试通知」按钮。测试提交只代表浏览器接受请求，请确认桌面横幅或通知中心是否收到；各浏览器与 Windows 通知权限组合仍需实机验收。

## 数据与升级

个人数据位于程序旁 `data/`：

- `config.json`：凭据、访问密码和监控列表。
- `posts.db`：帖子数据库。
- `browser_profiles/`：专用浏览器登录会话。
- `run.log`：打包版日志。

凭据仅保存在本机，登录及抓取时发送给相应平台。文件和浏览器会话仍属于敏感数据，请保护电脑账号及本地备份。断开连接会删除对应平台的凭据和专用浏览器会话，保留帖子及监控列表。

升级前关闭旧程序，备份整个 `data`，将新版完整解压到固定位置，再将自己的旧 `data` 整个复制到新版 exe 同级目录（不要放进 `_internal`）。现有旧版配置和帖子数据库沿用，数据库启动时自动新增全文状态字段，不删除旧帖；旧凭据可能需要重新登录。浏览器会话目录缺失时会在连接账号后创建。任意更早版本或第三方修改版尚未全部验证，迁移后先检查帖子、监控列表和登录状态；回退时使用升级前备份。

开机自启记录包含程序的绝对路径。换目录或改名后，先取消旧版自启，再运行新版目录内的 `exe_autostart_on.bat`；取消使用 `exe_autostart_off.bat`。新版脚本指向 `zhijian_silent.exe`，请勿沿用通过“只有一个 exe”判断程序的旧脚本。源码版的 `autostart_on.bat` 依赖该目录的 Python 虚拟环境，不适用于免安装发布包。启用新版自启后不要再运行旧版取消脚本，以免删除共用的自启项。

新版与旧版不要同时监控。分享必须使用干净的完整发布压缩包，不要发送自己正在使用的目录或自己的 `data`。访问密码属于本机页面保护，不提供公网部署能力。更多操作见 [分发说明](SHARING.md)。

## 打包与检查

双击 `build_exe.bat` 或 `build_exe_silent.bat`，均生成包含控制台和静默启动器的完整文件夹与 `dist/zhijian-windows.zip`。首次打包需要 PyInstaller、Chromium 和网络；发布包不包含个人 data。

开发检查：

```powershell
python -m unittest discover -s tests -v
python tests/ui_smoke.py
```

UI 测试需已安装 Chromium，使用隔离数据和本机测试端口 18765；测试不登录真实账号。真实扫码、重启复用和失效重连仍需逐平台人工验收。

本项目用于个人学习研究，请遵守平台规则。不要高频抓取或传播无权分享的内容。
