# 知见 · 多平台帖子监控

一个跑在自己电脑上的轻量监控台：把你在意的人**今天说了什么**聚到一个时间线里，新内容自动推送，全文入库可搜索。

支持平台：

| 平台   | 说明                               |
| ---- | -------------------------------- |
| 微博   | 指定博主的微博、转发、配图                    |
| 淘股吧  | 指定用户的帖子（公开内容免登录）                 |
| 知识星球 | 指定星球的帖子全文、图片                     |
| 公众号  | 通过「微信读书书架」桥接：订阅公众号后自动抓最新文章**全文** |

特性：

- 本地运行，数据不出你的电脑（SQLite 存储）
- 新帖子浏览器通知 + 红点提醒，支持全文/标题/作者搜索
- 正文、配图、原文链接一应俱全；图片走本地代理绕防盗链
- 凭证本地保存，微信读书 Cookie 自动续期
- 可后台静默运行、开机自启，也可打包成单文件 exe 送人

## 快速开始

### 方式一：源码运行（推荐）

1. 安装 [Python 3.10+](https://www.python.org/downloads/)（安装时**勾选 Add python.exe to PATH**）
2. 解压本项目，双击 `install.bat`（仅第一次，创建虚拟环境装依赖）
3. 双击 `start.bat`，浏览器打开 <http://127.0.0.1:8000>
4. 点右上角「⚙ 设置」，按下方教程填凭证、添加要监控的人

### 方式二：打包成 exe 分享

双击 `build_exe_silent.bat`，几分钟后在 `dist/` 得到 `zhijian_silent.exe`（无窗口静默版，日志写在 exe 同级的 `data/run.log`）。把这个 exe 单发给别人即可，**千万不要带上你自己的 data 文件夹**。对方双击运行后浏览器打开 <http://127.0.0.1:8000>。

另有 `build_exe.bat`（带控制台窗口版，方便看报错）。

### 开机自启 / 关闭

- 源码版：`autostart_on.bat` 开启（后台静默、开机自启），`autostart_off.bat` 关闭
- exe 版：把 exe 和 `exe_autostart_on.bat` 放同一文件夹后双击它；`exe_autostart_off.bat` 关闭

### 重新打包 zip 分享源码

双击 `pack_zip.bat`，自动生成干净的 `zhijian-post_monitor.zip`（自动排除 data、虚拟环境、exe）。

## 凭证获取教程

所有凭证都存在**你自己电脑**的 `data/config.json` 里，程序不会上传任何数据。Cookie 都有有效期，过期后界面顶栏会变红提醒，重新粘贴即可。

### 微博（必填 Cookie）

1. 浏览器打开 <https://m.weibo.cn> 并登录（建议用小号）
2. 按 `F12` 打开开发者工具 → 「网络/Network」标签
3. 刷新页面，随便点一条对 `m.weibo.cn` 的请求
4. 右侧「标头/Headers」→「请求标头」里找到 `Cookie:`，**整条复制**
5. 粘贴到知见设置页的「微博 Cookie」（关键是里面要有 `SUB=` 字段）

### 淘股吧（可选）

公开帖子不登录也能抓，不填也能用。需要抓登录可见内容时：登录 <https://www.taoguba.com.cn>，同样用 F12 → 网络 → 复制整条 Cookie 填入。

### 知识星球（必填 Token）

1. 浏览器打开 <https://wx.zsxq.com> 并登录
2. F12 → 「网络」→ 刷新，点任意一条对 `api.zsxq.com` 的请求
3. 请求标头里找到 `Authorization:`，复制它**的值**（一长串字母数字，不含 "Authorization:" 本身）
4. 粘贴到「知识星球 Token」
5. 添加星球：星球的 ID 在星球主页网址里，形如 `wx.zsxq.com/dweb2/index/group/88888888888`，填那串数字

### 公众号（微信读书书架桥，推荐玩法）

原理：微信读书 App 里订阅公众号后，它会以"书"的形式出现在你的书架，知见通过你的微信读书网页版登录态，自动发现书架上的公众号并抓最新文章全文。

1. **手机**打开微信读书 App → 搜索你要的公众号 → 点「订阅」（每个要监控的号都订一遍）
2. **电脑**浏览器打开 <https://weread.qq.com> 并微信扫码登录
3. F12 → 「网络」→ 刷新页面 → 点任意一条对 `weread.qq.com` 的请求
4. 请求标头里复制**整条 Cookie**（字段越全越好，至少含 `wr_vid`、`wr_skey`、`wr_rt`）
5. 粘贴到知见设置页的「微信读书 Cookie」→ 保存
6. 点「🔄 同步书架」→ 书架上的公众号会列出来 → 逐个「＋ 添加」→ 保存

之后程序每次轮询会自动续期 Cookie，基本不用管。以后加新公众号：App 里订阅 → 回来再点一次「同步书架」。

> 说明：微信读书网页端不开放公众号历史文章列表，所以监控粒度是"追最新一篇"——发新文章后下一轮轮询就会推送，不会漏，但不补历史旧文。

## 隐私

你的**全部个人数据都在 `data/` 文件夹里**：

- `data/config.json` —— 所有 Cookie/Token（最高敏感）
- `data/posts.db` —— 抓过的帖子库
- `data/run.log` —— 运行日志

分享时把 `data/` 整个删掉（或不要提交）即可，程序下次启动会自动重建空配置，**不影响任何功能**。

## 常见问题

**Q：微博突然集体报"Cookie 失效"？**
微博风控偶尔抽风，先等几小时；若两个号同时失效，去 m.weibo.cn 重新登录再复制最新 Cookie。依然不行请到 Issues 反馈（可能是接口变了）。

**Q：轮询间隔多少合适？**
默认 120 秒。监控的人多建议 300 秒，降低风控概率。

**Q：想部署到服务器/公网？**
设置页填「访问密码」即可开启登录页。默认监听 `127.0.0.1`，公网部署请自行修改 `main.py` 里的 host 并务必设密码。

**Q：停止后台运行的 exe？**
任务管理器结束 `zhijian_silent.exe`，或运行对应的 `autostart_off.bat`。
